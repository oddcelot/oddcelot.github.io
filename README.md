# oddcelot.github.io

The origin root of oddcelot.github.io. Project sites publish under their own
paths, but crawlers only read `robots.txt` and `/sitemap.xml` at the root of
the origin, so those live here, along with an index page and `llms.txt`.

When a project site is added or its sitemap moves, update `sitemap.xml`,
`robots.txt` and `llms.txt`.
