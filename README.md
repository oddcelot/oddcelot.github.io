# oddcelot.github.io

The origin root of oddcelot.github.io: `robots.txt`, `/sitemap.xml`, an
index page and `llms.txt`. Crawlers only read the first two at the root of
an origin. Project sites now live on their own domains (the
vite-plugin-lit docs at https://vite-plugin-lit.oddsquad.dev/), and GitHub
redirects their old oddcelot.github.io paths there.

When a project site moves or is added, update `index.html` and `llms.txt`.
